    SilkWheel：我做了一个让 Windows 鼠标滚轮更丝滑的小工具

    最近我做了一个很小的 Windows 桌面工具，叫 SilkWheel。

    它解决的是一个非常日常、但又很容易被忽略的问题：普通鼠标滚轮在 Windows 上滚动网页、文档、文件列表时，经常会有一种“一格一格跳”的机械感。滚轮转一下，页面就明显跳一段；连续滚动时，也容易觉得不够顺、不够稳。

    SilkWheel 想做的事情很简单：让鼠标滚轮滚起来更安静、更平顺、更可控。

    它不是为了把滚动做得花哨，而是把每一次滚轮输入转换成一段短而自然的惯性滑动。你还是用原来的鼠标，还是正常滚轮操作，但页面移动的感觉会更接近“顺着手走”，而不是硬生生一段一段跳。

    官网地址：

    https://silkwheel.raymondstudio.cn/

    GitHub 项目：

    https://github.com/RaymondGuoCGI/SilkWheel

    为什么我想做这个工具

    我自己每天大量使用鼠标：看网页、读文档、翻教程、管理文件、在不同软件之间切换。时间一长，Windows 普通鼠标滚轮那种段落感会变得很明显。

    触控板的滚动通常比较丝滑，但一换成普通鼠标滚轮，就很容易回到“咔、咔、咔”的感觉。尤其是读长文档或网页时，滚动如果太生硬，会让注意力一直被页面跳动打断。

    所以我开始做 SilkWheel。它是一个常驻托盘的小工具，运行后会在系统层面接管鼠标滚轮输入，再把滚动拆成更细、更平滑的运动。

    我的目标不是做一个复杂的大软件，而是做一个打开之后就能感受到差异的小工具。

    SilkWheel 现在能做什么

    目前这个 Beta 版本主要围绕几个核心体验：

    • 让垂直鼠标滚轮滚动更平滑。
    • 支持不同手感方案，可以快速切换。
    • 支持应用排除，某些软件可以保留原生滚轮行为。
    • 支持托盘常驻、开机启动、设置窗口和退出控制。
    • 支持亮色、灰色、暗色和自定义主题。
    • 官网支持中英双语，方便国内外用户体验。

    它的使用方式也尽量保持轻量：下载、运行、选择一个合适的手感，然后让它留在托盘里工作。

    现在是免费 Beta 阶段

    SilkWheel 目前不是急着收费，而是先做免费公测。

    我的想法是：用户可以免费使用 21 天。到期后，不需要付费，只需要提交一次真实使用反馈，就可以继续使用当前 Beta 版本。

    这样做的原因很直接。现在这个阶段，对我来说最重要的不是先收多少钱，而是知道：

    • 大家会在哪些软件里使用 SilkWheel。
    • 哪些鼠标型号滚起来更舒服，哪些还不够好。
    • 默认参数是太快、太慢，还是尾端还有跳动。
    • 哪些手感方案更接近日常使用里的“舒服”。

    这类反馈比早期付费更有价值。SilkWheel 这种工具，只有真的用一段时间，才知道它有没有改善每天的滚动体验。

    反馈现在可以直接提交

    官网上已经有反馈表单，不需要额外打开邮件客户端，也不需要复制粘贴到别的地方。

    用户在官网提交反馈后，内容会直接进入 SilkWheel 的反馈系统。我可以在后台面板里集中查看，然后根据这些反馈继续调整滚动算法、默认方案、排除应用、界面细节和下载流程。

    反馈不用很长，简单说清楚就有价值。比如：

    • 你用的是什么鼠标。
    • 你主要在哪些软件里测试。
    • 滚动感觉是偏快、偏慢、卡顿，还是舒服。
    • 哪个手感方案最适合你。
    • 有没有某些软件不适合开启平滑滚动。

    如果你遇到问题，也可以去公开反馈区提 issue：

    打赏和 Beta 解锁是分开的

    目前 SilkWheel 的策略是反馈优先，不是付费优先。

    如果它真的改善了你的日常滚动体验，也欢迎自愿支持开发。官网上已经放了 PayPal 和微信支持入口，但这和 Beta 使用、Beta 解锁是分开的。

    换句话说：你不打赏，也可以通过提交真实反馈继续使用当前 Beta。打赏只是对这个工具和后续打磨的一种自愿支持。

    适合什么人

    我觉得 SilkWheel 特别适合这几类用户：

    • 长时间用鼠标浏览网页、文档、教程的人。
    • 对 Windows 默认滚轮段落感不满意的人。
    • 不想换鼠标或触控板，但希望滚动更舒服的人。
    • 经常在浏览器、文件管理器、编辑器里滚动内容的人。
    • 喜欢自己调节手感、主题和应用排除规则的人。

    如果你平时只偶尔滚动两下，可能感觉不强。但如果你每天都在大量滚动页面，它带来的差异会更明显。

    后续计划

    接下来我会继续围绕“手感”打磨，而不是急着堆功能。

    优先级最高的还是几个问题：滚动尾端是否足够自然、高频滚动时是否稳定、不同软件里的兼容性如何、默认方案是否适合大多数人。

    如果你也觉得 Windows 鼠标滚轮可以更丝滑一点，欢迎下载试试。哪怕只反馈一句“在哪个软件里好用 / 不好用”，对这个阶段的 SilkWheel 都很有帮助。
