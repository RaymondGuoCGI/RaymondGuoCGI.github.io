    东方万年历：一个专为效率控设计的黄历择日工具

    在数字化时代，我们对时间的掌控早已不再局限于简单的时钟，更多的是对 时机的把握。

    市面上虽然有很多万年历 App，但它们大多充斥着各种理财广告、臃肿的资讯流，甚至连加载一个日期都要等上好几秒。为了解决这个痛点，我亲手打造了一个极简、纯净且专业的万年历系统 —— Raymond Calendar。

    1. 为什么叫东方万年历？

    虽然它采用了最现代的 Next.js + Tailwind CSS 框架构建，但它的灵魂是东方的。它深度集成了传统黄历算法，能精准地为你提供每日的宜与忌。无论是搬家入宅、开张开业，还是婚嫁祭祀，你都能一目了然。

    2. 核心功能亮点

    • 极简 Zen 设计：拒绝一切干扰，只有日期、黄历与你。支持白天/黑夜模式切换，适配不同读屏习惯。
    • 响应式体验：无论是在宽大的显示器上，还是在手机的小屏幕里，它都能完美呈现，甚至可以作为 PWA（渐进式 Web 应用）直接添加到手机桌面。
    • 中英双语支持：为了方便全球用户，我们内置了专业的中英双语翻译。
    • 法定节假日同步：自动标记国内的法定休假与调休安排，再也不会记错放假日子。

    3. 技术栈与未来

    该项目目前托管在 Vercel 平台上，并与我的 Obsidian 工作流深度集成。未来，我计划加入更多的个人化定制功能，比如与 Google Calendar 或 Outlook 的双向同步。

    4. 立刻体验

    希望这个工具能帮你找到那个对的时间，让生活更加顺遂。
