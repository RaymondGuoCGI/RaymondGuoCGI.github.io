    Agent Platform Kit Privacy Policy

    Effective date: 2026-08-10

    Agent Platform Kit does not collect or transmit user data to the developer or to any developer-controlled server. It contains no analytics, telemetry, advertising, tracking, remote code, or third-party SDK.

    Data Handled Locally

    The extension temporarily handles only what is required for its Basic features:

    • local JPG, PNG, or WebP files the user explicitly drops into the native Agent Platform Studio Composer;
    • the current native prompt and attachment state needed to avoid racing New chat restoration and image attachment;
    • the current model, Aspect ratio, and output resolution.

    Image data stays in page memory while it is validated, optionally re-encoded at the same pixel dimensions, and handed to Agent Platform Studio’s native file input. It is not persisted by the extension. Only the last model ID/label, Aspect ratio, and output resolution are stored locally in Chrome extension storage.

    Interaction With Google Cloud

    The extension uses the already-open Google Cloud page and the user’s existing session. It hands user-dropped local images to the page’s native attachment input and uses native controls to restore the user’s model, Aspect ratio, and output resolution after New chat.

    The extension never clicks Submit, never creates a model request, never fills prompts, and never retries a user’s request. It observes trusted native New chat and Submit clicks only to capture and restore the user’s selected settings.

    Permissions

    The extension uses Chrome’s storage permission and a narrow Google Cloud host/content-script scope for the Agent Platform Studio Multimodal Prompt page.

    Remote Code

    None. All JavaScript and CSS used by the extension is packaged in the extension directory.

    Retention And Deletion

    • Image-processing data is released after the drop transaction completes, or when the tab reloads or closes.
    • Saved model, Aspect ratio, and output resolution remain in local extension storage until they are replaced or the extension is uninstalled.
    • Uninstalling the extension removes its locally stored preferences according to Chrome’s extension-storage behavior.

    Contact

    For questions or bug reports, contact the project owner who provided this extension.
