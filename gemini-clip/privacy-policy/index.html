Gemini Clip Privacy Policy

Last updated: September 17, 2026

Release: 0.3.113

Gemini Clip processes selected Gemini conversation content in your browser. It does not transmit conversation content, images, settings, or task records to the developer, advertising networks, analytics services, or a developer-operated processing server. Requested imports and submissions interact with Google's Gemini service under your existing account.

Content handled

When you open Review, the extension can read selected conversation text and images and capture the current Gemini draft, including attachments that can be matched safely. Recent file objects from your drag, paste, or file selection may be retained temporarily in memory. Selected text, image references or bytes, additional instructions, and destinations are used for your requested import, submission, repeat, drag, or download.

Import fills a draft without sending. Import & submit and Submit perform the corresponding action you choose. Optional repeated sends execute the task configuration you explicitly start. Refresh recovery restores unfinished tasks paused and requires manual Resume.

Downloads and local image processing

Original mode retrieves the available original image bytes and preserves their supported file format. Clean mode processes compatible visible Gemini image marks locally. The document-start image filter may transform matching full-size Gemini image responses in memory before a later download. Merely hovering or selecting an image does not start a download.

The combined Good response & download action selects Gemini's Good response state when needed and starts the download. A separate optional setting, off by default, starts a download after you click Gemini's native Like control. Download status is monitored through Chrome's download manager.

Optional AI-texture correction is local and disabled by default. Image processing does not send pixels to a processing server and does not remove or claim to remove invisible provenance such as SynthID or Content Credentials. Verified clean images may be cached briefly in memory for repeat downloads.

Local storage and retention

The extension uses local extension storage, session storage, and short-lived memory for:

  • Preferences, language, shortcuts, download modes, and repeated-task options.
  • Last selection, last reviewed step, target conversations, temporary import payloads, and recoverable unfinished tasks. These can include prompt text and selected image bytes needed to complete your action.
  • Task ownership and account-scope identifiers that separate recovery between Gemini tabs/accounts.
  • Up to 30 recent terminal task records, including status, completion time, normalized prompt text, attachment names, and bounded image thumbnails. History details do not retain the original full-size attachment files. Older records may contain fewer details.
  • Local runtime diagnostics containing extension/build version, load time, and account scope. These are not telemetry and are not sent to the developer.

Clear History removes the local history records and saved details. Task removal and the relevant Clear controls remove their corresponding data. Clearing extension data or uninstalling removes extension-owned storage. Temporary pending imports expire; saved preferences and retained history are not represented as automatically expiring.

Optional Pause while reviewing images uses pointer movement only in the current page's memory to delay the next action. Pointer coordinates are not recorded in persistent storage or transmitted. The extension does not collect cross-site browsing history or behavioral analytics.

Repeated tasks can continue while another browser tab is active when that option is enabled. An active task may temporarily prevent automatic tab discarding; its prior discard setting is restored when the guard ends. Page refresh does not automatically resume submissions. Service-error pauses require manual Resume; any recommended waiting time is displayed separately.

Permissions

  • activeTab: lets the popup address the active Gemini tab for user-requested actions.
  • downloads: saves requested original or processed images and follows their download completion or failure.
  • offscreen: provides local image decoding and canvas processing outside the visible page.
  • storage: retains the preferences, import state, task recovery/history, and local diagnostics described above.
  • unlimitedStorage: supports local image payloads that can exceed the standard extension storage quota.
  • gemini.google.com: supports conversation selection, current-draft capture, import, explicit submission, task controls, and image actions.
  • Google-hosted googleusercontent.com, googleapis.com, and gstatic.com resources: retrieve image resources involved in supported Gemini operations. These permissions do not authorize reading unrelated websites.

Remote code, payments, and sharing

Executable code is bundled with the extension. Gemini Clip contains no advertising, analytics, telemetry, or remote processing backend. It does not sell user data or use it for advertising, creditworthiness, or lending.

Optional support links open PayPal. Donations are voluntary and unlock no features. PayPal handles its own payment information; Gemini Clip does not process payments. Google's and PayPal's services are governed by their respective policies.
