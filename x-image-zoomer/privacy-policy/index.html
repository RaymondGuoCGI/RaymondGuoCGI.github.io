X Image Zoomer
Privacy Policy

Updated November 11, 2026 · Applies to version 0.1.2

X Image Zoomer makes pictures easier to read in X (Twitter)'s desktop photo viewer with wheel zoom, dragging and reset controls. It is an independent product and is not affiliated with X.

Processing in your browser

The extension inspects displayed picture elements and their media links in the native photo viewer so it can change how the picture is displayed. These element references and zoom positions are temporary page state. Pointer input is used only to perform the current zoom or drag; it is not recorded as an activity log.

The developer does not collect or receive posts, images, account information, personal communications, browsing history, pointer activity or usage statistics. The extension does not upload page content, fetch additional images, contact a developer server, run analytics or execute remote code. X continues to load its own website and media in the normal way.

Local preferences

The extension saves only the enabled setting, interface language (English or Chinese) and theme (dark or light) in Chrome's local extension storage on your device. It does not use cloud or sync storage. Remove these preferences by uninstalling the extension.

Site access and permissions

  • storage: stores the local preferences described above.
  • X/Twitter site access: the content script is limited to https://x.com/*, https://www.x.com/*, https://twitter.com/* and https://www.twitter.com/*. It detects the native photo viewer and responds to your zoom and drag actions there.

No access to unrelated websites, additional media CDN permissions, background worker, advertising, payment services or donation links is included in this version.

Sharing and retention

There is no developer-side data storage or third-party data processor for this extension. Temporary zoom state ends when the viewer is closed or the page is refreshed. Local preferences remain until changed or the extension is removed.

Contact

Contact the developer through Raymond Studio or the support link on the extension's Chrome Web Store listing when it becomes available.
